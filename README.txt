PYCODE — сайт школы Python

ЗАПУСК:
1. Распакуйте архив.
2. Откройте index.html в браузере.
3. Переходы между страницами работают без сервера.

СТРУКТУРА:
index.html       — главная
courses.html     — обучение + вход
payment.html     — счёт и демонстрационная оплата
css/style.css    — весь дизайн
js/app.js        — интерактивность
pdf/             — сюда положите свой PDF

PDF:
Замените файл:
pdf/python-pro-course.pdf
на свой файл с таким же названием.

ОПЛАТА:
Сейчас оплата демонстрационная. После нажатия кнопки сайт показывает доступ к скачиванию.
Для настоящих денег потребуется backend и подключение платёжной системы (например Payme/Click).

GOOGLE:
Сейчас кнопка Google работает как демонстрация входа.
Для настоящей регистрации через Google OAuth нужно подключить Google Identity Services + backend.

Важно:
Защищать PDF только средствами HTML/JS нельзя. Для реального платного сервиса файлы лучше отдавать через сервер после проверки оплаченного заказа.
